# Сессия 1 — языковая школа

100 услуг, 50 клиентов, 100 исторических записей. Каталог с поиском, скидками и сортировкой; редактирование услуг и фотографий; запись клиентов и ближайшие записи. Код администратора: **0000**. В исходном импорте значения длительности 30–120 переведены из минут в секунды, значения 1800–7200 сохранены как секунды. Исторические даты сохранены, поэтому окно ближайших записей может быть пустым до добавления текущих записей. Изображения включены в Assets и копируются при сборке.

## Запуск

Требуются Windows, .NET SDK 9 и MS SQL Server / Express. Выполняйте команды из этой папки.

1. Создайте базу, выполнив весь `Database/01_CreateAndImport.sql` в SSMS либо:

```powershell
sqlcmd -S '.\SQLEXPRESS' -E -C -b -f 65001 -i '.\Database\01_CreateAndImport.sql'
```

2. При необходимости измените имя сервера в `SchoolApp/connection.txt`. База: `Task09School`. Используется Windows-аутентификация. Учётной записи нужны права чтения и изменения данных; для установки базы — права её создания.

3. Соберите и запустите:

```powershell
dotnet build .\SchoolApp -c Release
dotnet run --project .\SchoolApp
```

Или откройте `Task09.sln` в Visual Studio с поддержкой .NET 9 и WPF.

## Состав

- `SchoolApp/` — исходники WPF и ресурсы.
- `Task09.sln` — решение Visual Studio.
- `Database/01_CreateAndImport.sql` — схема и начальное наполнение базы.
- `Install-Database.ps1` — установка через sqlcmd.

Для первичной установки SQL-скрипт создаёт отдельную базу и таблицы. Повторный импорт в существующие таблицы запрещён; имеющиеся данные сохраняются. NuGet-пакеты восстанавливаются при сборке. Не публикуйте пароли SQL Server в connection.txt; по умолчанию в нём нет секретов.
