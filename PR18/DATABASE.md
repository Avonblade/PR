# База данных ПР18

`PR18_MedicalInsurance` создаётся скриптом `Database/01_CreateAndSeed.sql`.

| Таблица | Данные и связи |
| --- | --- |
| `Users` | Учётные записи администратора, инспектора и бухгалтера |
| `Clients` | Застрахованные клиенты |
| `Clinics` | Лечебные учреждения |
| `Policies` | Договоры ДМС, ссылки на клиента и инспектора |
| `ClinicContracts` | Договоры СМК с клиниками |
| `Claims` | Заявки по договорам ДМС, ссылка на первичную заявку при осложнении |
| `Referrals` | Направления по заявкам и договорам с клиниками |
| `PremiumPayments` | Взносы по ДМС и отметка проверки бухгалтерией |
| `ClinicPayments` | Перечисления по направлениям, в том числе частичные |
| `InspectorReports` | Отчёты инспекторов за период и дата передачи в бухгалтерию |
| `GovernmentRecords` | Налоговые отчисления и статистические отчёты. Сумма заполняется только для отчислений |

Представления `PolicySummary` и `ReferralSummary` рассчитывают остатки по взносам и оплате услуг. Ограничения таблиц проверяют ссылки, уникальность номеров, интервалы дат и денежные значения. После изменения записи приложение проверяет межтабличные правила через `WorkflowErrors` в той же транзакции. При нарушении изменения откатываются. Поле `rowversion` защищает от записи поверх изменений другого пользователя.

Все начальные имена, телефоны, адреса и сведения об обращениях составлены для учебной базы.
