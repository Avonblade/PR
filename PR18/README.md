# Практическая работа 18 — страховая медицинская компания

Приложение WPF ведёт договоры добровольного медицинского страхования, заявки, направления и расчёты с клиниками. В разделах есть таблицы, поиск и сортировка. Для создания и редактирования записей открывается отдельная форма.

## Запуск

Требуются Windows, .NET SDK 9 и SQL Server / Express. Выполняйте команды из папки ПР18.

1. Создайте базу `PR18_MedicalInsurance`. Запустите `Database/01_CreateAndSeed.sql` в SSMS или выполните:

   ```powershell
   .\Install-Database.ps1
   ```

   Установка добавляет начальные данные. При наличии таблиц повторный импорт останавливается с сообщением и сохраняет существующие данные.

2. При необходимости измените сервер в `WPF_PR18_insurance_Zaytsev/connection.txt`. По умолчанию используется `.\SQLEXPRESS` и Windows-аутентификация.

3. Откройте `WPF_PR18_insurance_Zaytsev.sln` в Visual Studio или выполните:

   ```powershell
   dotnet run --project .\WPF_PR18_insurance_Zaytsev
   ```

## Учебные учётные записи

| Логин | Пароль | Доступ |
| --- | --- | --- |
| `admin` | `Smk18-Admin!` | Просмотр, добавление, редактирование и удаление во всех разделах |
| `inspector` | `Smk18-Inspector!` | Создание и редактирование заявок, направлений и отчётов инспекторов, просмотр договоров и справочников |
| `accountant` | `Smk18-Account!` | Проверка взносов, перечисления клиникам, учёт налогов и статистики, просмотр остальных разделов |

База хранит соль и хеш PBKDF2-SHA256 с 600 000 итераций. Эти роли действуют в приложении. Прямой доступ к SQL Server определяется правами учётной записи Windows.

## Рабочий сценарий

1. Администратор заводит клиента, его договор ДМС с ответственным инспектором и договор с клиникой.
2. Инспектор принимает заявку и оформляет направление. Для осложнения он заводит отдельную заявку по тому же договору и выбирает исходную заявку. Дата осложнения может выходить за срок полиса, если первичная заявка подана в период покрытия.
3. Бухгалтер проверяет поступившие взносы. В договорах ДМС видны проверенная сумма и остаток. Оплата клинике допускается после полной проверки взносов на дату перечисления. Можно записать частичную оплату в пределах стоимости направления.
4. Инспектор регистрирует передачу своего отчёта в бухгалтерию. Бухгалтер записывает перечисления налоговым органам и отправку статистической отчётности.
5. Администратор может удалить запись с подтверждением. Если на неё ссылаются другие записи, SQL Server останавливает удаление.

## Проверка

- Войти неверным паролем и убедиться, что рабочее окно не открывается.
- Под инспектором найти «осложнения» в разделе «Заявки». Открыть заявку `З-26003` и проверить связь с первичной `З-26001`. Проверить отсутствие кнопки удаления.
- Под бухгалтером открыть «Взносы клиентов» и отметить `ВЗ-26003` как проверенный. Остаток по договору `ДМС-26002` изменится с 16 000 ₽ до 0 ₽.
- Открыть «Направления» и проверить, что по `Н-26002` перечислено 6 000 ₽, а остаток составляет 6 600 ₽ до добавления новых перечислений.
- Под администратором добавить клинику, изменить её телефон и удалить эту новую запись.
