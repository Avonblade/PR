# Практическая работа 19 — «Фитнес-учёт»

Рабочие места администратора, менеджера по продажам, тренера и сотрудника стойки. Приложение ведёт клиентов, абонементы, посещения, расписание и записи на занятия.

## Запуск

Требуются Windows, .NET SDK 9 и SQL Server / Express. Команды выполняются из папки ПР19.

1. Выполните `Database/01_CreateAndSeed.sql` в SSMS либо запустите `.\Install-Database.ps1`. Скрипт создаёт отдельную базу `PR19_Fitness` и заполняет её учебными данными. При повторном запуске он сохраняет существующие записи.
2. Проверьте `WPF_PR19_fitness_Zaytsev/connection.txt`. По умолчанию указан сервер `.\SQLEXPRESS` с Windows-аутентификацией.
3. Откройте `WPF_PR19_fitness_Zaytsev.sln` в Visual Studio или выполните:

   ```powershell
   dotnet run --project .\WPF_PR19_fitness_Zaytsev
   ```

## Учебные учётные записи

| Логин | Пароль | Доступ |
| --- | --- | --- |
| `admin` | `Fit19-Admin!` | Клиенты, сотрудники, залы, расписание, абонементы, посещения и отчёты |
| `sales` | `Fit19-Sales!` | Продажа и продление, заморозка, контакты клиентов, история посещений, запись на занятия |
| `coach` | `Fit19-Coach!` | Расписание, участники и отметки на своих занятиях |
| `desk` | `Fit19-Desk!` | Статус клиента и абонемента, регистрация входа и выхода |
| `coach2` | `Fit19-Coach2!` | Второй тренер для проверки разграничения по занятиям |

Пароли хранятся в виде PBKDF2-SHA256 с отдельной солью и 600 000 итераций. Доступ к функциям проверяется и в интерфейсе, и в коде операций. Прямой доступ к SQL Server определяется правами учётной записи Windows.

## Правила учёта

- Даты абонемента включительны. Разовый действует в день начала и даёт одно посещение. Остальные типы действуют до дня перед датой, рассчитанной прибавлением месяца, квартала или года. У них можно задать лимит. Для продления оформите следующий абонемент с даты после окончания текущего.
- По условию ТЗ период заморозки располагается после действующего срока. После подтверждения статус сразу становится «Заморожен», а срок увеличивается на число календарных дней периода. Разморозка сохраняет новую дату окончания. При пересечении с другим абонементом операция отклоняется.
- Заблокированный клиент не может войти. Когда лимит равен нулю, приложение предлагает разовый вход или обращение к менеджеру за продлением. Гостевой вход бесплатен.
- Тренировки повторяются еженедельно, а запись относится к конкретной дате. Тренер отмечает присутствие после начала своего занятия. Отметка «Пришёл» создаёт одно групповое посещение. При записи по абонементу оно расходует одно посещение, при гостевой записи — не расходует.
- Список клиентов показывает текущий абонемент или ближайшую подходящую запись из истории, чтобы поддержать фильтр «Истёк». Значения «0», «1–3» и «Больше 3» относятся к абонементам с лимитом.

## Проверка

1. Войдите с неверным паролем, затем под администратором. Проверьте предупреждения по цветам и кнопки с правами администратора.
2. Совместите поиск «ВЕРА» с фильтрами «Активен», «Месячный», «В течение 7 дней» и «1–3». Сразу после установки останется Вера Климова. Нажмите «Сбросить фильтры» и дважды нажмите заголовок «ФИО».
3. Попробуйте оформить абонемент с прошедшей датой, пересекающимся сроком или текстом в поле лимита. Проверьте продление и заморозку на учебной записи.
4. Под сотрудником стойки найдите Илью Котова по карте `FIT-104`. Вход по абонементу отклоняется при нулевом остатке. В «Фиксации выхода» попробуйте время раньше входа.
5. В расписании найдите занятие «Мобильность» в малой студии. После заполнения двух мест третья запись отклоняется. Под тренером откройте список участников своего занятия. Для исходных записей при необходимости выберите неделю установки базы.
