# Единый стиль Alisa

Применён гайд из «Практическая работа 16.pdf»:

- Основной шрифт обоих окон — **Comic Sans MS**.
- Оригинальный логотип извлечён из PDF в `Resorce/logo.jpg`, без изменения изображения. Он показывается с сохранением пропорций через Stretch=Uniform.
- Иконка `Resorce/app.ico` создана по теме одежды с использованием палитры бренда; включена в EXE и установлена для окон.
- Все элементы каталога и формы товара используют общие стили `Resorce/Styles.xaml`.

Для интерактивных состояний также применены светлые оттенки и прозрачность базовых цветов. RGB и HEX взяты из текстовых подписей гайда, а не из пикселей изображения со сжатием.
