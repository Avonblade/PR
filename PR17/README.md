# Практическая работа 17 — ресторан «Мармеладная зебра»

Приложение WPF показывает меню при запуске. Гость может искать блюда, комбинировать фильтры и сортировать таблицу. После входа сотрудник может добавлять, редактировать и удалять блюда. Для добавления и редактирования используется отдельное окно.

Проект `WPF_PR17_restaurant_Zaytsev` использует Comic Sans MS, логотип из задания и фирменные цвета `#2B96D1`, `#E3217B`, `#FAE322`, белый и чёрный. Ресурсы находятся в `Resorce`, работа с базой — в `ApplicationData`, окна — в `MainPage`.

## Запуск

Требуются Windows, .NET SDK 9 и MS SQL Server / Express. Команды выполняются из папки этой работы.

1. Запустите `Database/01_CreateAndSeed.sql` в SSMS или выполните:

   ```powershell
   .\Install-Database.ps1
   ```

   Скрипт создаёт базу `PR17_ZebraRestaurant` на `.\SQLEXPRESS`. Если одноимённая пустая база уже подготовлена, скрипт создаёт в ней таблицы. При повторном запуске существующие таблицы и данные сохраняются.

2. При необходимости укажите свой сервер в `WPF_PR17_restaurant_Zaytsev/connection.txt`. Соединение с SQL Server использует Windows-аутентификацию.

3. Запустите приложение:

   ```powershell
   dotnet run --project .\WPF_PR17_restaurant_Zaytsev
   ```

   Также можно открыть `WPF_PR17_restaurant_Zaytsev.sln` в Visual Studio.

Для проверки редактора используется учебная учётная запись `editor` с паролем `ZebraMenu17!`. Пароль хранится в БД в виде PBKDF2-SHA256 с индивидуальной солью и 600 000 итераций. Вход сотрудника ограничивает операции в WPF. Права прямого доступа к SQL Server определяет учётная запись Windows.

## Схема базы

| Таблица | Назначение |
| --- | --- |
| `Dishes` | Блюдо, описание, цена и ссылки на три справочника |
| `Categories` | Категории блюд |
| `Cuisines` | Кухни |
| `ServingSizes` | Размеры порций |
| `Users` | Логин, имя, соль, хеш пароля и признак активности |

Начальное наполнение включает 13 блюд. Внешние ключи гарантируют существование значений справочников. Поле `rowversion` защищает от перезаписи и удаления устаревшей версии блюда.

## Проверка вручную

1. Запустите приложение. В гостевом режиме должны отображаться 13 блюд, а кнопки изменения меню должны быть недоступны.
2. Введите в поиск «БОРЩ», затем нажмите «Сбросить». В первом случае останется одно блюдо, во втором вернётся полный список.
3. Нажмите «Войти». Проверьте отказ с неверным паролем и вход с указанной выше учётной записью.
4. Создайте блюдо с тремя значениями справочников, измените его цену, затем удалите с подтверждением. Проверьте, что текст в поле цены отклоняется.
5. Нажмите «Выйти». Кнопки изменения меню снова должны стать недоступны.
