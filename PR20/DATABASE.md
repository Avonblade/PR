# База данных «ФотоСтудия»

| Таблицы | Назначение |
| --- | --- |
| `Staff`, `Clients` | Сотрудники и клиенты. История и средний чек выводятся по связанным броням |
| `Rooms`, `Props` | Залы, тарифы, реквизит, остатки и признаки ремонта |
| `Bookings`, `Reservations` | Расписание и состав брони. Тарифы фиксируются при выборе ресурсов |
| `Loans`, `Repairs` | Выдачи, возвраты, повреждённые единицы и интервалы ремонта |
| `Images`, `Materials` | Фотографии, пути, ссылки и статусы обработки. Одинаковые файлы определяются по SHA-256 |
| `Payments`, `Conflicts` | Журнал оплат и отклонённых попыток подтверждения или переноса |

Подтверждённые, оплаченные и взятые в работу брони резервируют зал, фотографа и позиции реквизита. Черновики могут пересекаться и показывают конфликт зала в календаре. Функция `PropFree` вычисляет остаток на интервале по максимальной одновременной занятости. Физический остаток на складе проверяется при выдаче. Изменения из приложения выполняются в сериализуемых транзакциях, а параллельные записи координируются блокировкой SQL Server.

## Отчёты

- **Залы.** Часы считаются внутри выбранного периода. При досрочном закрытии часы учитываются до момента закрытия. Выручка отражает внесённые в журнал платежи за период, средний чек — стоимость броней, попавших в расчёт часов.
- **Реквизит.** Стоимость учитывает реально выданные единицы и тариф из брони. Дни ремонта считаются по времени, когда в ремонте была вся позиция или хотя бы одна единица.
- **Долги.** В отчёт попадают остатки по сроку оплаты. По умолчанию срок — дата окончания съёмки, при согласовании используется дата из карточки. Просрочка начинается на следующий день.
- **Фотографы.** Завершённые съёмки учитываются по дате закрытия. Обработка измеряется от окончания запланированного интервала до готовности последнего готового материала. Доля возвратов и пересъёмок берётся из отметок в закрытых карточках.
- **Конфликты и отмены.** Учитываются причины отмены и сохранённые отклонения при подтверждении или переносе. Одна попытка может учитываться одновременно для зала и фотографа.
