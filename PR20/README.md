# Практическая работа 20 — «ФотоСтудия»

Приложение WPF для бронирования залов, ведения съёмок, учёта реквизита и оплаты. Данные хранятся в SQL Server.

## Запуск

Требуются Windows, .NET SDK 9 и SQL Server или SQL Server Express. Выполняйте команды из папки ПР20.

1. Выполните `Database/01_CreateAndSeed.sql` в SSMS или запустите `.\Install-Database.ps1`. Скрипт создаёт базу `PR20_PhotoStudio` с учебными записями. При повторном запуске существующие данные сохраняются.
2. Проверьте `WPF_PR20_studio_Zaytsev/connection.txt`. По умолчанию используется `.\SQLEXPRESS` с Windows-аутентификацией.
3. Откройте `WPF_PR20_studio_Zaytsev.sln` в Visual Studio или запустите:

   ```powershell
   dotnet run --project .\WPF_PR20_studio_Zaytsev
   ```

## Учётные записи

| Логин | Учебный пароль | Доступ |
| --- | --- | --- |
| `admin` | `Studio20-Admin!` | Все рабочие операции, справочники, цены, сотрудники и исправление завершённых броней |
| `manager` | `Studio20-Manager!` | Клиенты, брони, реквизит, платежи и квитанции, превью, закрытие съёмок и отчёты |
| `photo` | `Studio20-Photo!` | Свои съёмки, комментарии, материалы, приём реквизита и передача на закрытие |
| `store` | `Studio20-Store!` | Выдача и приём реквизита, фотографии состояния, остатки и ремонт |
| `photo2` | `Studio20-Photo2!` | Вторая учётная запись фотографа для проверки разграничения |

Пароли хранятся в виде PBKDF2-SHA256 с индивидуальной солью и 600 000 итераций. Эти роли действуют в приложении. Прямой доступ к SQL Server определяется правами учётной записи Windows.

## Проверка по ТЗ

- **Бронирование.** Откройте черновик `ФС-0004` и нажмите «Проверить время». В форме появятся пересечения по залу и фотографу и варианты с тем же временем или ближайшие свободные интервалы. Подтверждение повторно проверяет ресурсы. Соседние интервалы могут соприкасаться границами.
- **Стоимость и склад.** Сохраните черновик, откройте его карточку и подберите реквизит. Сумма состоит из тарифа зала за выбранное время и тарифов зарезервированных позиций. Для выдачи и возврата загрузите фото состояния. Повреждённые единицы уменьшают остаток до корректировки склада.
- **Съёмка.** Фотограф переводит свою подтверждённую бронь в работу, прикрепляет JPEG/PNG до 10 МБ и передаёт карточку на закрытие. В одной съёмке допустимо от трёх разных превью для завершения и до пяти в карточке. Исходники и готовые материалы хранятся как абсолютные пути или ссылки HTTP(S).
- **Оплата.** Запишите платёж с суммой, способом и номером чека. Журнал позволяет сохранить текстовую учебную квитанцию. Закрытие требует минимум три превью и фото возврата по каждой выдаче. При долге менеджер указывает согласование с клиентом и срок оплаты. После закрытия остаток можно погасить отдельным платежом.
- **Поиск и отчёты.** Совместите поиск по части имени или названию с фильтрами статуса, периода, зала, фотографа, наличия реквизита и суммы. Повторный щелчок по заголовку меняет сортировку. Администратору и менеджеру доступны пять отчётов за период.
